# Vrinda Store Sales Analysis

## Project Overview
This project analyzes a retail sales dataset to understand customer purchasing behavior, sales trends, and platform performance.

The goal was to extract insights that can help businesses improve inventory planning and marketing strategies.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Data Cleaning
- Data Visualization

## Project Objectives
- Analyze sales performance
- Identify top selling states
- Understand customer demographics
- Compare platform sales performance

## Data Cleaning
Before performing analysis, the dataset was cleaned by:

- Removing null values
- Fixing inconsistent entries
- Standardizing column formats

## Analysis Performed
The analysis focused on several key areas:

### Sales Trends
- Monthly order trends
- Monthly revenue trends

### Customer Demographics
- Gender-wise purchasing patterns

### Platform Analysis
- Sales comparison between different ecommerce platforms

### Regional Analysis
- Identification of top-performing states

## Key Insights
- Identified peak sales months
- Found the top 3 states generating the highest sales
- Observed differences in purchasing behavior across genders

## Skills Demonstrated
- Data cleaning
- Pivot table analysis
- Dashboard creation
- Data visualization

## Outcome
This project shows how retail sales data can be analyzed to understand customer behavior and improve business strategy.
